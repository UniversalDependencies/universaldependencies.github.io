root: root

The root grammatical relation points to the root of the sentence. A fake node ROOT is used as the governor. The ROOT node is indexed with 0, since the indexing of real words in the sentence starts at 1.

There is just one node with the root dependency relation in every tree. If the main predicate is not present (due to ellipsis) and there are multiple orphaned dependents, the dependent that is highest in the obliqueness hierarchy is promoted to the head (root) position and the other orphans are attached to it.
