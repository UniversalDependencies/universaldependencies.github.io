Description

Chechen-MottDT is a Universal Dependencies treebank of the Chechen language (Nakh-Daghestanian). The annotation for part of speech tags and features was coverted from interlinear glosses, while dependencies were annotated manually. The treebank contains 3160 tokens.

The Chechen-MottDT treebank contains three oral folktales; the respective sentence IDs start with ‘spoken’. In addition, the treebank contains examples from the Chechen contribution to BivalTyp (the Typological Database of Bivalent Verbs and Their Encoding Frames). The respective sentence IDs start with ‘grammar’. The texts included are as follows.

  • spoken_bear: an oral folktale, 235 tokens
  • spoken_wolf: an oral folktale, 668 tokens
  • spoken_witch: an oral folktale, 1832 tokens
  • grammar_examples: examples from the Chechen contribution to BivalTyp, 425 tokens
