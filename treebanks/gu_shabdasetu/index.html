Description

ShabdaSetu is an in-progress treebank of Gujarati (an Indo-Aryan language) in Gujarati script.

Currently the treebank is comprised of 38 sentences. It was annotated following the Universal Dependencies (UD) framework. The treebank covers a range of grammatical constructions including conditional clauses, relative clauses, correlative constructions, conjunctive participles, and light verb constructions. Morphological features and dependency relations are annotated manually in Gujarati script.

Acknowledgments

The treebank agrees with the existing GujTB treebank and uses it as a reference to build upon. The treebank was manually annotated by Dhairushi Patel. Supervision and revision by Luigi Talamo, Annemarie Verkerk.
