Description

UD_Evenki-GDUD is a treebank of Evenki, a Northern Tungusic language spoken across a vast area of Siberia and northeastern China, based on grammatical example sentences derived from a reference grammar.

The Evenki GDUD (Grammar-Derived Universal Dependencies) treebank contains 39 sentences of Evenki (ISO 639-3: evn), a Northern Tungusic language spoken by the Evenki people across a wide area of eastern Siberia (Russia) and in Heilongjiang and Inner Mongolia (China). Evenki is closely related to Even and Negidal. The data consist of grammatical example sentences drawn from a reference grammar of Evenki, presented in a phonemic Latin-based transcription and accompanied by English translations and interlinear glosses.

All sentences are manually annotated with lemmas, universal part-of-speech tags (UPOS), morphological features, and dependency relations, following the Universal Dependencies (UD) guidelines. The annotation prioritizes UD core morphological features and dependency relations. Evenki-specific morphological distinctions that do not correspond to any value in the universal feature inventory are encoded in the MISC column, in accordance with UD conventions.

Data split

Because the treebank is small (well below the 20K-word threshold), all sentences are provided as test data.

Morphological annotation

All UD core features used in the treebank take standard universal values.

Dependency annotation

UD core relations are used throughout the treebank.
