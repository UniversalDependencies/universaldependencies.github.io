Description

UD_Nanai-GDUD is a treebank of Nanai (also called Hezhen or Golds), a Southern Tungusic language spoken in the Amur region of the Russian Far East and in northeastern China, based on grammatical example sentences derived from a reference grammar.

The Nanai GDUD (Grammar-Derived Universal Dependencies) treebank contains 113 sentences of Nanai (ISO 639-3: gld), a Southern Tungusic language spoken by the Nanai people along the middle and lower Amur River in the Russian Far East and in Heilongjiang Province of China. The data consist of grammatical example sentences drawn from a reference grammar of Nanai, presented in a phonemic Latin-based transcription and accompanied by English translations and interlinear glosses.

All sentences are manually annotated with lemmas, universal part-of-speech tags (UPOS), morphological features, and dependency relations, following the Universal Dependencies (UD) guidelines. The annotation prioritizes UD core morphological features and dependency relations. Nanai-specific morphological distinctions that do not correspond to any value in the universal feature inventory are encoded in the MISC column, in accordance with UD conventions.

Data split

Because the treebank is small (well below the 20K-word threshold), all sentences are provided as test data.

Morphological annotation

All UD core features used in the treebank take standard universal values.

Dependency annotation

UD core relations are used throughout the treebank.
