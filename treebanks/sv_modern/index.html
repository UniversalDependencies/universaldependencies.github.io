Description

UD_Swedish-Modern is a treebank containing texts from Modern Swedish (1526–1880).

UD Swedish-Modern is a treebank containing texts from the Modern Swedish period, traditionally dated from 1526 to 1880. It is part of the project Swedish Diachronic Treebank, which also includes treebank texts from Old Swedish (1225–1526) in the treebank UD_Swedish-Old. The project is coordinated by Språkbanken CLARIN.

Currently, the treebank contains text from only one source: the 1526 Swedish New Testament translation, covering the Gospel of Mark. Since the treebank is very small, there is currently only test data and no training or development data.

The text is based on the 2026 release of the 1526 New Testament, by Lasse Mårtensson.
