Description

The Kullvi UD Treebank (KDTB) is a part of the Universal Dependencies treebank project.

The Kullvi UD Treebank (KDTB) contains linguistically annotated data for the Kullvi language and is a part of the Universal Dependencies treebank project. The treebank provides syntactic annotation according to the Universal Dependencies framework, along with morphological and part-of-speech annotations. In this data, XPOS tags are annotated according to the Bureau of Indian Standards (BIS) Part-of-Speech (POS) tagset.

Kullvi is an Indo-Aryan language spoken primarily in the Kullu region of Himachal Pradesh, India. The purpose of this treebank is to provide a standardized dependency-annotated resource for Kullvi and to support research in natural language processing, computational linguistics, and low-resource language technologies.
