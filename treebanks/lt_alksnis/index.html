Description

The Lithuanian dependency treebank ALKSNIS-UD (Vytautas Magnus University, Kaunas, Lithuania).

This is a new version of the ALKSNIS-UD treebank natively annotated following Universal Dependencies.

ALKSNIS-UD consists of 3,070 syntactically annotated sentences. Each node of a tree corresponds to a word or another sentence unit (such as punctuation marks or numerals). The following information is presented for each node: a used form, a lemma, and a morphology tag. Dependencies between words are represented by indicating their syntactic functions. The corpus is provided in the CoNLL-U format. Dependency trees can be visualised using the CoNLL-U editor available at https://github.com/Orange-OpenSource/conllueditor

Syntactically annotated sentences are annotated according to guidelines of the Universal Dependencies (UD) standard: https://universaldependencies.org/. The Lithuanian UD guidelines are available here: https://hdl.handle.net/20.500.11821/110. All the sentences are being manually checked and corrected by a group of linguists. Compiled during 2024–2026.
